How It Works

An end-to-end production ML pipeline designed for robust unsupervised clustering and fast sub-millisecond serving.

1. Multicollinearity Filtering

Removed highly correlated features (> 0.8 correlation) to prevent distortion in Euclidean distance calculations.

2. Selective log1p & Scaling

Imputed medians, applied np.log1p selectively to 11 right-skewed columns, and standardized via StandardScaler.

3. Silhouette Optimization

Iterated KMeans across k ∈ [3, 8], logging Silhouette and Davies-Bouldin metrics to pinpoint optimal k=3.

4. Persona Profiling

Inspected centroid z-scores against ±0.5 std dev thresholds to generate plain-English segment personas.

5. Fast-Inference Classifier

Trained a Random Forest (200 trees) on KMeans labels, reaching 98.4% accuracy for instant sub-millisecond scoring.

6. Low-Latency REST API

Packaged with FastAPI using a "load once, serve many" lifespan context manager and Pydantic schema validation.
